# 📘 Diary Management Web App

A simple web application for managing personal diary entries.

## 🛠 Technologies Used
- **ASP.NET Core MVC**
- **SQL Server**

## ✨ Features
- Add, edit, and delete diary entries (CRUD operations)
- Each diary entry includes:
  - Title
  - Content
  - Date
- Preloaded with 3 initial entries in the database
- Clean and user-friendly UI
- Structured to support future features like:
  - User authentication
  - Account-based entry management

## 📄 Project Summary
Developed a web application for managing personal diary entries using ASP.NET Core MVC and SQL Server. Each diary entry consists of a title, content, and date, with full Create, Edit, and Delete (CRUD) functionality. The user interface is designed for ease of use and efficiency, allowing users to seamlessly manage their diary entries. The project includes three initial entries in the database and is structured to support future extensions such as user authentication and account-based entry management.

## 🚀 Getting Started
1. Clone the repository.
2. Update the connection string in `appsettings.json` to point to your SQL Server.
3. Run database migrations or ensure the database is created.
4. Launch the application via Visual Studio or `dotnet run`.
